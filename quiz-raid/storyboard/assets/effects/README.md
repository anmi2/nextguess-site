# QUIZ RAID 通常攻撃エフェクト

公開サイト `/quiz-raid/storyboard/` の通常攻撃画像（透明PNG）の保存先です。

- `C001_magic.png` — 玲：赤い魔力弾
- `C002_slash.png` — 絢：青白い氷の斬撃
- `C003_impact.png` — エリン：橙色の魔力打撃
- `C004_music.png` — フィーダ：翡翠色の音符

公開ページでは各画像を `./assets/effects/<filename>` として読み込みます。まだPNGをアップロードしていない場合は、簡易記号エフェクトを代替表示します。

回答：正解時はモンスターに攻撃エフェクト、不正解時はプレイヤーのドット絵に赤い発光・振動。判定と演出は500msで次の問題に自動移行。

注意：スキル専用エフェクトは未実装です。
