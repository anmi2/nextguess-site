# QUIZ RAID 公開プレビュー画像

このフォルダは公開サイト `/quiz-raid/storyboard/` に表示する画像専用です。

元の開発用リポジトリ `anmi2/quiz-raid` は **private** なので、その `raw.githubusercontent.com` 画像URLは公開サイトから取得できません。

必要なPNGファイル（全52枚）を **この同じフォルダへ** アップロードしてください。サブフォルダは不要です。

- 通常モンスター：`M001.png`〜`M027.png`（27枚）
- セミボス：`B001.png`〜`B009.png`（9枚）
- キャラクター：`C101.png`〜`C104.png`、`C201.png`〜`C204.png`、`C301.png`〜`C304.png`、`C401.png`〜`C404.png`（16枚）

公開プレビューHTMLは同じディレクトリの `assets/<filename>` を参照します。
画像データのみ公開され、開発リポジトリ本体を公開する必要はありません。
